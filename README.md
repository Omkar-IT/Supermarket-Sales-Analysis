# Supermarket Sales Analysis Project

## Project Overview
This project performs an exploratory data analysis on supermarket transactional data to discover revenue patterns, category performance, and sales distribution across product lines.

## Dataset
- **Dataset Name**: Supermarket Sales Dataset
- **Source**: Kaggle (Fares Ashraf)
- **Description**: Transaction records from a supermarket chain with detailed attributes including branch, customer type, product line, and sales figures.

## Technologies Used
- Python 3.13
- Pandas (Data Cleaning & Manipulation)
- Matplotlib (Data Visualization)
